Musicify 14.0 — provider integration preview
Based on 13.2. Existing origin, manifest, library and official YouTube player retained.
New: configurable HTTPS provider, music/permission checks, compatible audio format selection and quality preference, audio action in YouTube search results. No provider is bundled. No YouTube extraction or claim of working YouTube background playback.
Provider contract: GET configured endpoint with id and quality query parameters; CORS must permit Musicify origin. JSON example: {"id":"VIDEO_ID","authorized":true,"music":true,"title":"Song","artist":"Artist","audio":[{"url":"https://your-authorized-host/song.m4a","mimeType":"audio/mp4","bitrate":128000}]}. Provider must actually have rights; flags are not proof. Use stable audio URLs supporting range requests. No secrets in endpoint. Audio is played through existing HTML5 audio and Media Session. Single-track provider playback only; provider queue refresh not implemented. Test on iPhone before deployment. Export library backup first. ytify source reviewed as architectural reference; no code copied.
