Musicify 14.4.0 — discovery preview
Upload existing frontend files to Cloudflare as usual. The discovery-backend folder is a separate Python service, not executable by static hosting. Deploy it separately using the included Dockerfile, with HTTPS and MUSICIFY_ORIGIN set to your frontend origin. Restrict access/rate-limit at the hosting gateway before public use. Free hosting is not guaranteed. In Settings save the HTTPS backend base URL and test discovery. Without it the existing Google API search remains available. The backend vendors the supplied MIT ytmusicapi snapshot and license. No credentials required for public search. Chart playlists link externally; no audio extraction or background YouTube playback is added. Artist/album detail and recommendations endpoints are not included in this preview. Live service and iPhone tests remain necessary.
