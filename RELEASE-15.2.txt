Musicify 15.2 — Navidrome preview
Install Navidrome on Windows from https://www.navidrome.org/docs/installation/windows/ and configure a folder of music you own. Create a dedicated non-admin user. Musicify requires a trusted HTTPS URL and a server/reverse proxy permitting CORS for the Musicify origin. Local plain HTTP is not supported from the hosted HTTPS PWA. Do not expose an unprotected server to the internet. No server is installed or configured by this ZIP. In Library > Personal music · Navidrome, enter the HTTPS base URL and credentials, connect, search or browse recently added albums, then play. Authentication uses the Subsonic salted MD5 token protocol over HTTPS. Tokens are reusable credentials, not expiring tokens; do not share stream URLs. Reconnect after reload. No offline downloads or persistent Navidrome library sync. Existing providers remain available. Live server and iPhone testing required.
