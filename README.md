# Musicify
Two independent local-first implementations. No paid music catalogue or account required.

## Windows / PWA
Install Python 3 from python.org (select Add Python to PATH). Open PowerShell in the extracted folder. Run `cd pwa` then `py -m http.server 8080`. Open http://localhost:8080 in your Windows browser. For iPhone installation, deploy the contents of pwa to a free HTTPS static host such as GitHub Pages (public repository; do not upload personal audio). Open the resulting HTTPS URL in Safari, Share > Add to Home Screen. Open once online before offline use. Import audio through Library. Browser storage can be cleared by iOS; retain original files. HTTP LAN addresses do not provide reliable service worker/offline support.

## Windows / native iPhone
Install current Node.js LTS from nodejs.org and Expo Go from App Store. Open PowerShell in extracted folder and run `powershell -ExecutionPolicy Bypass -File .\Setup-Native.ps1`. This creates an Expo blank project and installs SDK-matched packages. Scan the QR with iPhone camera on the same Wi-Fi; if needed run `npx expo start --tunnel` from MusicifyNative. Expo Go is a test environment, not a permanent standalone installation. Native background/lock screen capabilities require a compatible Expo SDK and may need a custom build. Apple signing and distribution can require paid membership and macOS or a cloud build service. No CarPlay or Waze integration is included.

## Usage
Import your legally acquired audio, search Audius independent music, or enter a permitted HTTPS direct audio/radio URL. Online results depend on API availability, licensing, region, and network. No automatic downloading of online tracks. Gym and Driving playlists are included; use + to add. PWA prompts for playlist name; native adds to the currently selected playlist name. Home recommendations rank your own play counts. Lyrics are manually entered notes, not synchronised. Play counts count starts. Visualizer is decorative, not audio-reactive. Sleep timers may be delayed when suspended. PWA and native libraries are separate. Bluetooth uses iOS system routing.

## Scope and validation
PWA JavaScript syntax checked. Native project source supplied with setup script; dependencies, live APIs, browser and iPhone playback have not been runtime tested in this environment. EQ, synced lyrics, advanced AI, Navidrome integration, automatic offline downloads of online tracks, CarPlay and Waze are not implemented. Audio quality and format support depend on platform and source. No credentials are included. Do not operate the interface while driving.

## Version 3: YouTube discovery (PWA)
Upload every file in pwa/ to the existing HTTPS GitHub Pages site. Reload twice if the previous service worker is still active. Open YouTube tab. Paste a public embeddable video URL to play without an API key. For search, create a project at https://console.cloud.google.com/, enable YouTube Data API v3, create an API key under Credentials, restrict it to YouTube Data API v3 and your website HTTP referrer (e.g. https://YOURNAME.github.io/*). Enter the key in the app and save for this session. Never commit the key. Search consumes quota; default quota is typically 10,000 units/day and search costs 100 units. Results are newest matching uploads, not verified charts or release dates. The official visible player retains ads and restrictions; no offline YouTube downloads or audio extraction. Favourites and history are local and separate from audio playlists. Native source remains v1; YouTube integration is PWA only. Syntax checked, not live API or iPhone tested.
